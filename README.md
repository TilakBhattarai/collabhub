# CollabHub

CollabHub is a full-stack collaboration and team matching platform
that helps people find collaborators, build projects, and work together.

## Tech Stack

- Frontend: React, Tailwind CSS
- Backend: Django, Django REST Framework
- Database: PostgreSQL
- Authentication: JWT

## Current Features

### Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Access & Refresh Token Handling

### User Profile
- Create User Profile
- Edit Profile
- Profile Picture Upload
- Skills
- Bio
- Role
- Location
- Experience
- GitHub
- Portfolio
- Availability
- Looking For

### Dashboard
- User Dashboard

### Discover
- Discover other users
- View user profile information
- Send connection requests

### Connections
- Send Connection Requests
- View Pending Connection Requests
- Prevent Duplicate Connection Requests
- Prevent Connecting With Yourself
- Validate Invalid Users
- Display Sender Profile Information
- Display Profile Pictures
- Responsive Connections UI

## Project Status

CollabHub is currently under active development.

The current focus is building the core collaboration and connection system.

Upcoming features will include:

- Accept / Decline Connection Requests
- Connected Users
- Remove Connections
- Improved Connection States
- Notifications
- Project Collaboration
- AI-powered Team Matching

## Project Goal

The goal of CollabHub is to create a platform where developers,
students, designers, and other creators can discover people with
similar interests and skills, form teams, and collaborate on real-world
projects.

## Development

Built with React, Django REST Framework, PostgreSQL, and JWT
